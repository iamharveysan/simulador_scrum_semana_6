# Review & Retro Lab

Simulador interactivo en React para Semana 6 de Scrum.

## Incluye
- Registro de nombre, apellido y carrera.
- Briefing del Sprint.
- 8 situaciones prácticas.
- Feedback inmediato.
- Puntuación final.
- Certificado PDF personalizado.
- Animaciones con Framer Motion.

## Ejecutar
```bash
npm install
npm run dev
```

Luego abre la URL que indique Vite, normalmente:
http://localhost:5173
